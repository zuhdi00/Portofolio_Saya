PROPOSAL PENGADAAN SERVER

Upgrade Infrastruktur IT Perusahaan

Tahun 2025

1. LATAR BELAKANG

Dalam rangka meningkatkan efisiensi operasional dan mendukung pertumbuhan perusahaan manufaktur yang kini memiliki 100-200 karyawan, diperlukan pengadaan server yang handal untuk mengelola sistem informasi perusahaan, meliputi:

  • Sistem manajemen produksi dan inventory
  • Database karyawan dan payroll
  • File server untuk dokumen perusahaan
  • Email dan sistem komunikasi internal
  • Backup dan keamanan data

Server baru ini diharapkan dapat melayani kebutuhan operasional selama 3-5 tahun ke depan dengan performa yang optimal.

2. TUJUAN PENGADAAN

  • Meningkatkan kecepatan akses dan pengolahan data perusahaan
  • Menyediakan platform yang stabil untuk aplikasi bisnis
  • Meningkatkan keamanan dan backup data
  • Mengurangi downtime sistem yang dapat mengganggu produktivitas
  • Menyediakan infrastruktur untuk digitalisasi proses bisnis

5. JUSTIFIKASI PEMILIHAN SPESIFIKASI

Intel Xeon Silver 4210 (10 Core, 20 Thread)
Prosesor entry-level Xeon yang handal untuk menangani workload perusahaan menengah. Dengan 10 core, mampu menjalankan multiple aplikasi dan melayani 100-200 user secara bersamaan dengan baik.

16 GB ECC RAM
ECC (Error Correcting Code) RAM mencegah data corruption dan lebih stabil untuk server. Kapasitas 16GB cukup untuk kebutuhan saat ini dan dapat diupgrade hingga 64-128GB jika diperlukan.

1 TB SSD + 2 TB HDD
Kombinasi SSD untuk kecepatan akses sistem dan aplikasi, serta HDD untuk penyimpanan data yang lebih ekonomis. Total kapasitas 3TB cukup untuk data perusahaan menengah.

Dual Gigabit Ethernet
Dua port network memberikan redundansi dan load balancing. Jika satu port bermasalah, server tetap dapat diakses melalui port kedua.

6. MANFAAT YANG DIHARAPKAN

  • Peningkatan Performa: Akses data 3-5x lebih cepat dibanding sistem lama
  • Kapasitas Memadai: Dapat menangani 100-200 user concurrent dengan lancar
  • Stabilitas Sistem: Uptime lebih baik dengan komponen server-grade
  • Keamanan Data: ECC RAM dan dual storage mencegah kehilangan data
  • Skalabilitas: Dapat diupgrade RAM dan storage sesuai pertumbuhan bisnis
  • Cost Effective: Budget terjangkau dengan performa optimal untuk perusahaan menengah
  • ROI: Investasi 3-4 tahun tanpa perlu upgrade signifikan

8. REKOMENDASI VENDOR

Untuk mendapatkan harga terbaik, disarankan melakukan survey ke beberapa vendor:

  • Distributor server lokal (HP, Dell, Lenovo reseller)
  • Toko komputer spesialis server (Harco Mangga Dua, ITC, dll)
  • Online marketplace B2B (Bhinneka, Rakuten, dll)
  • Vendor IT lokal yang trusted

Lakukan perbandingan minimal 3 vendor untuk mendapatkan penawaran terbaik dalam range budget Rp 28-32 juta.

9. KESIMPULAN

Pengadaan server dengan spesifikasi Intel Xeon Silver 4210, 16GB RAM, 1TB SSD + 2TB HDD dalam casing PC standard ATX merupakan solusi yang tepat dan cost-effective untuk kebutuhan perusahaan manufaktur dengan 100-200 karyawan.

Dengan budget Rp 21-25 juta (Paket Standard - Rekomendasi), perusahaan akan mendapatkan server yang handal, stabil, dan dapat menunjang operasional selama 3-4 tahun ke depan. Penggunaan casing PC standard memudahkan perawatan dan upgrade di masa depan, serta instalasi in-house membantu menghemat biaya implementasi.

Tersedia juga pilihan paket mulai dari Rp 10 juta (Paket Basic) hingga Rp 30 juta (Paket Premium) yang dapat disesuaikan dengan kebutuhan dan kondisi budget perusahaan.

Server ini akan meningkatkan efisiensi kerja, keamanan data, dan mendukung proses digitalisasi perusahaan ke depannya.
