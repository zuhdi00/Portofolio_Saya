2. DESKRIPSI MASALAH
2.1 Ringkasan Masalah

Terjadi gangguan konektivitas jaringan antara server dan komputer client ketika kabel LAN CCTV tersambung pada switch Flexo. Jaringan berfungsi normal setelah kabel CCTV dicabut dari switch.

2.2 Kondisi Jaringan
⚠️ KONDISI SAAT KABEL CCTV TERPASANG DI SWITCH FLEXO:
  • Koneksi server ke client BERMASALAH
  • Jaringan mengalami gangguan/terputus
  • Komunikasi data tidak stabil
  • CCTV dapat terhubung namun mengganggu jaringan utama
✓ KONDISI SETELAH KABEL CCTV DICABUT DARI SWITCH FLEXO:
  • Koneksi server ke client NORMAL
  • Jaringan berjalan lancar
  • Komunikasi data stabil
  • Tidak ada gangguan konektivitas

       |           ←── (Kabel CCTV dicabut = jaringan normal)

5. ANALISIS KEMUNGKINAN PENYEBAB

Berdasarkan gejala yang terjadi, berikut kemungkinan penyebab masalah:

No Kemungkinan Penyebab Penjelasan
1 Bandwidth Overload Kapasitas bandwidth switch tidak mencukupi untuk menangani traffic data + CCTV secara bersamaan. CCTV streaming video membutuhkan bandwidth besar yang menghabiskan kapasitas switch.
2 Broadcast Storm Perangkat CCTV mengirimkan paket broadcast berlebihan yang membanjiri jaringan, menyebabkan kemacetan dan timeout koneksi.
3 Loop Jaringan Terjadi loop pada topologi jaringan ketika CCTV terhubung, menyebabkan paket data berputar terus-menerus di jaringan.
4 Tidak Ada QoS Switch tidak memiliki pengaturan Quality of Service untuk memprioritaskan traffic data penting, sehingga traffic CCTV mengambil alih seluruh bandwidth.
5 Port/Duplex Mismatch Pengaturan kecepatan atau mode duplex port tidak sesuai, menyebabkan collision dan packet loss.
6 Kabel Rusak Kabel CCTV berkualitas rendah atau mengalami kerusakan, mengirimkan sinyal error yang mengganggu switch.
7 IP Conflict Perangkat CCTV memiliki IP address yang sama dengan perangkat lain di jaringan.
8 Switch Kapasitas Rendah Spesifikasi switch Flexo tidak dirancang untuk menangani beban jaringan data dan CCTV secara bersamaan.

7. REKOMENDASI SOLUSI
7.1 Solusi Jangka Pendek (Segera)

Rekomendasi Utama:

  1. Pisahkan Jaringan CCTV
    • Gunakan switch terpisah khusus untuk sistem CCTV
    • Hubungkan switch CCTV langsung ke router utama (bypass switch Flexo)
    • Isolasi traffic CCTV dari jaringan data operasional
  2. Temporary Workaround
    • Sementara cabut kabel CCTV dari switch Flexo untuk menjaga kelancaran operasional
    • Hubungkan CCTV ke port router lain atau switch cadangan jika tersedia
7.2 Solusi Jangka Panjang (Permanent)

Rekomendasi Infrastruktur:

  1. Upgrade Switch
    • Ganti switch Flexo dengan managed switch berkapasitas Gigabit
    • Pilih switch dengan fitur QoS, VLAN, dan port mirroring
    • Estimasi budget: [sesuaikan budget]
  2. Implementasi VLAN
    • VLAN 10: Jaringan Data (Server-Client)
    • VLAN 20: Jaringan CCTV
    • Pisahkan traffic untuk menghindari collision
  3. Konfigurasi QoS
    • Prioritas tinggi: Traffic data operasional
    • Prioritas sedang: Traffic CCTV
    • Limit bandwidth CCTV maksimal 40-50% total bandwidth
  4. Tambah Switch Dedicated CCTV
    • Sediakan 1 switch khusus untuk sistem surveillance
    • Switch CCTV terhubung langsung ke NVR/DVR
    • Tidak bergabung dengan switch jaringan data
  5. Upgrade Kabel
    • Gunakan kabel Cat6 atau Cat6a untuk CCTV
    • Pastikan kabel sesuai standar T568A/B
    • Test semua kabel dengan LAN tester

⚠️ PERHATIAN:

  • Masalah ini berdampak pada produktivitas karena gangguan koneksi server-client
  • Diperlukan penanganan segera untuk memastikan operasional tidak terganggu
  • Disarankan melakukan perencanaan infrastruktur jaringan yang lebih baik

9. KESIMPULAN

Berdasarkan troubleshooting yang dilakukan, dapat disimpulkan bahwa:

  1. Masalah konektivitas jaringan antara server dan client disebabkan oleh kabel LAN CCTV yang terpasang pada switch Flexo
  2. Switch Flexo tidak mampu menangani beban traffic data dan CCTV secara bersamaan
  3. Jaringan kembali normal dan stabil setelah kabel CCTV dicabut dari switch Flexo
  4. Diperlukan pemisahan jaringan CCTV atau upgrade infrastruktur untuk solusi permanen
