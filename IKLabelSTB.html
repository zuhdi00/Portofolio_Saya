INSTRUKSI KERJA

Pembuatan STB (Serah Terima Barang) Label

Nomor Dokumen : IK-STB-001 Revisi : 01
Tanggal Efektif : 23 Oktober 2025 Halaman : 1 dari 10
Departemen : Enterprise Data Protection Status : Aktif
1. TUJUAN

Instruksi kerja ini bertujuan untuk memberikan panduan kepada operator dalam membuat dan mengelola STB Label yang akan digunakan untuk identifikasi dan tracking barang di gudang.

2. RUANG LINGKUP

Instruksi kerja ini mencakup proses pembuatan STB Label mulai dari input data hingga penyimpanan barang di gudang STB PT. Supracor Sejahtera Corrugated Carton Box.

3. DOKUMEN TERKAIT
  • Order Produksi (OP)
  • Surat Jalan / Delivery Order
  • Standar Operating Procedure (SOP) Warehouse

6. PROSEDUR KERJA DETAIL
1
Input Nomor Order Produksi (OP)

Tindakan:

1.1 Buka Aplikasi STB Label

• Login ke sistem menggunakan username dan password yang telah diberikan

• Pastikan printer label sudah terhubung dan siap digunakan

1.2 Masukkan Nomor OP

• Pada kolom "No OP", ketik nomor Order Produksi

• Format contoh: SPS/2301/00215-B01

• Pastikan nomor OP yang diinput sesuai dengan dokumen Order Produksi

1.3 Klik Tombol "Cari" atau Tekan Enter

• Klik tombol Cari atau tekan tombol Enter pada keyboard

• Sistem akan menampilkan data order yang sesuai

📸 Screenshot: Halaman Input Nomor OP

Tampilan form dengan kolom No OP dan tombol Cari

💡 Tips:
  • Pastikan nomor OP sudah ada dalam sistem
  • Jika data tidak muncul, cek kembali nomor OP atau hubungi admin
2
Input Data STB dan Print Label

Tindakan:

2.1 Verifikasi Data Order yang Muncul

Setelah nomor OP ditemukan, sistem akan menampilkan data:

  • Tanggal Cetak: 7 Oktober 2025
  • Tanggal Kirim: 12 Januari 2023
  • No. OP: SPS/2301/00215-B01
  • Pemesan: KUSUMA MUKTI REMAJA, PT
  • Nama Barang: MG KUSUMA 18-L PREMIUM GOLD
  • Ukuran: 270 x 250 x 311
  • Kualitas: K200 / M150 / K150 / K150 / K200
  • Flute: SCF
  • Jumlah Order: 0pcs
  • Jumlah PCS/Ikat: 10pcs/Ikat
  • Jumlah Pra Per Pallete: 0pcs
  • Jumlah Tambahan: PCS

Pastikan semua data sudah benar!

2.2 Input Nomor STB Terbaru

• Pada kolom "No. STB", masukkan nomor STB terbaru

• Format contoh: STB-3510081S

• Nomor ini harus unik dan sequential (berurutan)

2.3 Input Nama Kepala Shift

• Pada kolom "Kepala Shift", masukkan nama kepala shift yang bertugas

• Contoh: Budi Santoso

• Pastikan nama ditulis dengan lengkap dan benar

2.4 Input Jumlah Koli/Pallete

• Pada kolom "Jumlah Koli/Pallete", masukkan jumlah koli atau pallete

• Isi dengan angka sesuai jumlah aktual

• Contoh: 50 (untuk 50 koli)

2.5 Input Jumlah Tambahan

• Pada kolom "Jumlah Tambahan", masukkan jumlah tambahan (jika ada)

• Satuan: PCS

• Jika tidak ada tambahan, isi dengan 0

2.6 Save dan Print

• Klik tombol Save untuk menyimpan data

• Kemudian klik tombol Print Preview untuk preview label

• Jika sudah sesuai, lanjutkan print label

📸 Screenshot: Form Input Data STB

Tampilan form lengkap dengan semua field yang harus diisi

⚠️ PERHATIAN:
  • Pastikan semua data sudah diisi dengan benar sebelum klik Save
  • Cek kembali nomor STB agar tidak duplikat
  • Printer harus dalam kondisi siap (ada kertas dan tinta cukup)
3
Tempel Label di Pallet dan Bawa ke Gudang STB

Tindakan:

3.1 Ambil Label yang Sudah Dicetak

• Ambil label STB dari printer

• Pastikan label tercetak dengan jelas (QR Code harus bisa terbaca)

• Label akan berisi informasi lengkap order dan QR Code

Tanggal Kirim : 12 Januari 2023

No. OP : SPS/2301/00215-B01
Pemesan : KUSUMA MUKTI REMAJA, PT
Nama Barang : MG KUSUMA 18-L PREMIUM GOLD
No. MC : 0022075
Kepala Shift : [Nama]
QR

Jumlah: 0pcs

3.2 Tempel Label di Pallet

• Tempelkan label STB pada tumpukan kardus per pallet

• Posisi label harus mudah terlihat dan mudah di-scan

• Rekomendasi: tempel di bagian depan atas pallet

• Pastikan label menempel dengan kuat (tidak mudah lepas)

3.3 Transport ke Gudang STB

• Gunakan forklift atau alat bantu lain untuk memindahkan pallet

• Bawa pallet yang sudah diberi label ke area Gudang STB

• Pastikan barang tidak rusak selama proses pemindahan

• Tempatkan sementara di area staging sebelum proses scan

💡 Tips Penempelan Label:
  • Bersihkan permukaan sebelum menempel label
  • Hindari menempel di area yang basah atau kotor
  • Label harus menghadap ke arah yang mudah diakses scanner
4
Scan Barcode Menggunakan Aplikasi "Barcode SPS"

Tindakan:

4.1 Buka Aplikasi "Barcode SPS"

• Buka aplikasi "Barcode SPS" di smartphone atau scanner

• Login dengan akun yang sudah diberikan

• Pastikan koneksi internet aktif (untuk sinkronisasi data)

4.2 Pilih Menu Scan

• Pilih menu "Scan Barcode" atau "Scan STB"

• Kamera akan aktif untuk scan QR Code

4.3 Scan QR Code pada Label STB

• Arahkan kamera ke QR Code pada label STB

• Pastikan QR Code berada dalam frame kamera

• Jaga jarak ±15-20 cm untuk hasil scan optimal

• Tunggu hingga aplikasi berbunyi/bergetar tanda scan berhasil

4.4 Data Otomatis Muncul

• Setelah scan berhasil, data order akan muncul di layar aplikasi

• Data yang muncul meliputi:

  • Nomor STB
  • Nomor OP
  • Nama Pemesan
  • Nama Barang
  • Jumlah Koli/Pallet
  • Tanggal Kirim
  • Kepala Shift
📸 Screenshot: Aplikasi Barcode SPS

Tampilan aplikasi saat scan dan data yang muncul

⚠️ PERHATIAN:
  • Pastikan pencahayaan cukup saat scan QR Code
  • Jika scan gagal, bersihkan kamera atau coba dari sudut berbeda
  • QR Code tidak boleh rusak, kotor, atau terlipat
5
Verifikasi Data dan Approval

Tindakan:

5.1 Verifikasi Kesesuaian Barang

Cek kesesuaian data di aplikasi dengan barang fisik:

Item yang Dicek Cara Verifikasi
Nomor OP Cocokkan dengan dokumen Order Produksi
Nama Barang Pastikan jenis kardus sesuai spesifikasi
Jumlah Koli Hitung fisik jumlah koli/pallet
Ukuran Cek dimensi kardus (panjang x lebar x tinggi)
Kualitas Cek jenis flute dan material
Kondisi Fisik Pastikan kardus tidak rusak/cacat
5.2 Proses Pengecekan

Jika barang SESUAI:

✅ Lanjutkan ke proses approval

✅ Klik tombol Approve atau Terima

✅ Sistem akan mencatat waktu dan user yang melakukan approval

Jika barang TIDAK SESUAI:

❌ Klik tombol Reject atau Tolak

❌ Input alasan penolakan (misal: jumlah tidak sesuai, barang rusak, dll)

❌ Informasikan ke supervisor/kepala shift

❌ Pisahkan barang untuk proses rework atau investigasi

5.3 Lakukan Approval

Setelah memastikan barang sesuai:

  1. Klik tombol Approve
  2. Konfirmasi approval (jika diminta)
  3. Tunggu notifikasi "Approval Berhasil"
  4. Data akan tersimpan di sistem dan status berubah menjadi "Approved"
5.4 Catat di Log Book (Opsional)

• Catat di log book manual sebagai backup:

  • Nomor STB
  • Tanggal dan waktu
  • Nama petugas
  • Status approval
  • Catatan khusus (jika ada)
💡 Tips Verifikasi:
  • Lakukan double check untuk order dengan jumlah besar
  • Jika ragu, konsultasikan dengan supervisor
  • Foto barang sebagai dokumentasi (jika diperlukan)
  • Pastikan tidak ada barang tercampur dari order lain
6
Simpan Barang di Gudang STB

Tindakan:

6.1 Tentukan Lokasi Penyimpanan

• Pilih lokasi penyimpanan berdasarkan:

  • Tanggal kirim: Order dengan tanggal kirim paling dekat diletakkan di area yang mudah diakses
  • Jenis customer: Grouping berdasarkan customer untuk memudahkan picking
  • Ukuran barang: Barang besar di area khusus
  • FIFO (First In First Out): Barang yang masuk lebih dulu keluar lebih dulu
6.2 Tempatkan Pallet di Lokasi yang Tepat

• Pindahkan pallet menggunakan forklift

• Tempatkan di rak atau area yang sudah ditentukan

• Pastikan label STB tetap terlihat jelas

• Jangan menumpuk terlalu tinggi (sesuai standar safety)

6.3 Update Lokasi di Sistem (Jika Ada Fitur)

• Jika aplikasi "Barcode SPS" memiliki fitur update lokasi:

  • Input kode lokasi penyimpanan (misal: A-01-01)
  • Klik Save Location
  • Sistem akan mencatat posisi barang di gudang
6.4 Rapikan Area Penyimpanan

• Pastikan pallet tersusun rapi

• Gang/jalan akses tetap terbuka

• Tidak menghalangi jalur evakuasi

• Area bersih dari sampah atau material lain

✅ Proses Selesai!

Barang sudah berhasil tersimpan di Gudang STB dengan status:

  • ✓ Label STB terpasang
  • ✓ Data ter-record di sistem
  • ✓ Status: Approved
  • ✓ Lokasi penyimpanan tercatat
  • ✓ Siap untuk proses pengiriman
7. CHECKLIST PROSES PEMBUATAN STB LABEL
  • Nomor OP sudah diinput dan data order berhasil ditampilkan
  • Nomor STB terbaru sudah diinput (pastikan tidak duplikat)
  • Nama Kepala Shift sudah diisi dengan benar
  • Jumlah Koli/Pallet sudah diisi sesuai actual
  • Jumlah Tambahan sudah diisi (atau 0 jika tidak ada)
  • Data sudah di-save dan label berhasil dicetak
  • QR Code pada label tercetak dengan jelas
  • Label sudah ditempel di pallet pada posisi yang mudah terlihat
  • Pallet sudah dibawa ke area Gudang STB
  • QR Code berhasil di-scan menggunakan aplikasi "Barcode SPS"
  • Data yang muncul sudah diverifikasi dan sesuai dengan barang
  • Approval sudah dilakukan di aplikasi
  • Barang sudah disimpan di lokasi yang tepat di Gudang STB
  • Lokasi penyimpanan sudah di-update di sistem (jika ada)

9. HAL YANG HARUS DIPERHATIKAN (PENTING!)

⚠️ PERHATIAN KHUSUS:

  1. Akurasi Data: Pastikan semua data yang diinput 100% akurat, kesalahan input dapat menyebabkan salah kirim
  2. Nomor STB Unik: Setiap STB harus memiliki nomor unik yang tidak boleh duplikat
  3. Label Harus Jelas: QR Code dan teks pada label harus terbaca dengan jelas, jangan menempel di area yang rusak atau basah
  4. Verifikasi Wajib: Selalu lakukan verifikasi fisik barang sebelum approval, jangan hanya mengandalkan data di sistem
  5. FIFO: Terapkan sistem First In First Out untuk menghindari barang kadaluarsa atau terlalu lama di gudang
  6. Dokumentasi: Jika menemukan ketidaksesuaian atau masalah, segera foto dan laporkan ke supervisor
  7. Kebersihan: Jaga kebersihan label dan area penyimpanan agar QR Code tetap mudah di-scan
