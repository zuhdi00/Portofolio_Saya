STANDAR OPERATING PROCEDURE (SOP)

PEMBUATAN STB (SERAH TERIMA BARANG) LABEL

PT. Supracor Sejahtera Corrugated Carton Box

1. TUJUAN

Memberikan panduan kepada operator dalam membuat dan mengelola STB Label yang digunakan untuk identifikasi dan tracking barang di gudang secara akurat dan efisien.

2. RUANG LINGKUP

Proses pembuatan STB Label mulai dari input data hingga penyimpanan barang di gudang STB PT. Supracor Sejahtera Corrugated Carton Box.

3. ALAT DAN APLIKASI YANG DIGUNAKAN
No Alat/Aplikasi Fungsi
1 Komputer Mengakses sistem dan mencetak label
2 Aplikasi STB Label System Generate STB Label
3 Printer Label Mencetak STB Label dengan QR Code
4 Smartphone/Scanner Scan barcode menggunakan aplikasi "Barcode SPS"
5 Aplikasi "Barcode SPS" Verifikasi dan approval barang di gudang
4. PROSEDUR KERJA
TAHAP 1: PERSIAPAN DAN INPUT DATA
  1. Operator memastikan semua alat siap digunakan (komputer, aplikasi, printer)
  2. Login ke sistem dengan kredensial yang benar
  3. Siapkan Order Produksi (OP) yang akan diproses
  4. Input nomor OP ke dalam sistem STB Label
  5. Verifikasi data order yang muncul di layar sudah sesuai
TAHAP 2: PEMBUATAN LABEL
  1. Input nomor STB terbaru (pastikan tidak duplikat dengan yang sebelumnya)
  2. Isi nama Kepala Shift dengan benar
  3. Input jumlah Koli/Pallet sesuai actual di lapangan
  4. Input jumlah tambahan (atau 0 jika tidak ada)
  5. Review kembali semua data input untuk memastikan akurasi 100%
  6. Klik tombol "Save" untuk menyimpan data
  7. Pastikan printer label siap dengan kertas label yang cukup
  8. Klik "Print" untuk mencetak label STB
  9. Verifikasi QR Code pada label tercetak dengan jelas dan terbaca
TAHAP 3: PENEMPATAN LABEL DAN PENGIRIMAN
  1. Tempel label STB di pallet pada posisi yang mudah terlihat dan tidak akan rusak
  2. Pastikan label menempel kuat dan permanen
  3. Bawa pallet ke area Gudang STB
TAHAP 4: VERIFIKASI DAN APPROVAL
  1. Scan QR Code pada label menggunakan smartphone dengan aplikasi "Barcode SPS"
  2. Pastikan data yang muncul di aplikasi sudah sesuai dengan barang fisik
  3. Verifikasi jumlah barang, OP number, dan detail lainnya
  4. Klik tombol "Approval" untuk menyelesaikan proses jika data sudah benar
  5. Simpan barang di lokasi yang tepat di Gudang STB sesuai sistem
  6. Update lokasi penyimpanan di sistem (jika fitur tersedia)
5. CHECKLIST PROSES PEMBUATAN STB LABEL
6. HAL-HAL PENTING YANG HARUS DIPERHATIKAN
  1. Akurasi Data: Pastikan semua data yang diinput 100% akurat, kesalahan input dapat menyebabkan salah kirim
  2. Nomor STB Unik: Setiap STB harus memiliki nomor unik yang tidak boleh duplikat
  3. Label Harus Jelas: QR Code dan teks pada label harus terbaca dengan jelas, jangan menempel di area yang rusak atau basah
  4. Verifikasi Wajib: Selalu lakukan verifikasi fisik barang sebelum approval, jangan hanya mengandalkan data di sistem
  5. FIFO: Terapkan sistem First In First Out untuk menghindari barang kadaluarsa atau terlalu lama di gudang
  6. Dokumentasi: Jika menemukan ketidaksesuaian atau masalah, segera foto dan laporkan ke IT
7. TROUBLESHOOTING - MASALAH DAN SOLUSI
Masalah Penyebab Solusi
Data OP tidak muncul Nomor OP salah atau belum di-input ke sistem; Koneksi database error Cek kembali nomor OP; Hubungi admin untuk verifikasi; Restart aplikasi/komputer
Label tidak keluar/stuck di printer Kertas label habis; Printer jam/error; Driver printer bermasalah Isi ulang kertas label; Reset printer; Reinstall driver printer
QR Code tidak terbaca saat scan QR Code rusak/kotor; Pencahayaan kurang; Kamera kotor/blur Print ulang label; Pindah ke area dengan cahaya lebih baik; Bersihkan lensa kamera
Data yang muncul tidak sesuai Scan label yang salah; Data di sistem tidak update; Nomor STB duplikat Pastikan scan label yang benar; Hubungi IT untuk sync data; Generate nomor STB baru
Approval tidak bisa dilakukan Koneksi internet terputus; User tidak punya akses; Aplikasi crash Cek koneksi internet; Login ulang dengan user yang benar; Restart aplikasi
Nomor STB duplikat Nomor tidak sequential; Input manual salah; Sistem tidak update Cek nomor STB terakhir di database; Generate nomor baru; Hubungi admin sistem
