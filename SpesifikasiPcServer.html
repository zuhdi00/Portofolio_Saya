PROPOSAL PENGADAAN SERVER

Upgrade Infrastruktur IT Perusahaan

Tahun 2025

1. LATAR BELAKANG

Seiring dengan perkembangan perusahaan manufaktur yang kini memiliki 100-200 karyawan, kebutuhan akan infrastruktur IT yang handal dan scalable menjadi sangat penting. Server yang ada saat ini sudah tidak mampu menangani beban kerja yang terus meningkat, termasuk:

  • Sistem ERP (Enterprise Resource Planning)
  • Database produksi dan inventory
  • File server untuk data perusahaan
  • Email server dan aplikasi kolaborasi
  • Sistem backup dan disaster recovery

Oleh karena itu, diperlukan pengadaan server baru dengan spesifikasi enterprise-grade yang dapat mendukung operasional perusahaan untuk 3-5 tahun ke depan.

2. TUJUAN PENGADAAN

  • Meningkatkan performa dan reliability sistem IT perusahaan
  • Menyediakan platform yang scalable untuk pertumbuhan bisnis
  • Meningkatkan keamanan data perusahaan
  • Mengurangi downtime dan meningkatkan produktivitas karyawan
  • Menyediakan infrastruktur untuk digitalisasi proses manufaktur

5. JUSTIFIKASI PEMILIHAN SPESIFIKASI

Intel Xeon Platinum 8380

Prosesor kelas enterprise dengan 40 core yang mampu menangani workload berat seperti virtualisasi, database processing, dan aplikasi multi-threaded. Ideal untuk perusahaan dengan 100-200 user concurrent.

32 GB ECC RAM (Expandable 256 GB)

ECC RAM mencegah data corruption. Kapasitas 32GB cukup untuk operasional saat ini dengan ruang ekspansi hingga 256GB untuk kebutuhan future-proofing tanpa perlu replace hardware.

Dual Storage System (SSD + HDD)

Kombinasi SSD NVMe untuk performa tinggi pada OS dan aplikasi, serta HDD untuk storage kapasitas besar yang cost-effective. RAID configuration memberikan redundancy dan data protection.

Dual 10GbE Network

Menyediakan bandwidth tinggi untuk transfer data dan redundansi network. Mendukung pertumbuhan infrastruktur IT dan integrasi dengan sistem warehouse/production.

6. MANFAAT YANG DIHARAPKAN

  • Peningkatan Produktivitas: Response time sistem lebih cepat 5-10x dibanding server lama
  • Skalabilitas: Dapat menampung pertumbuhan user hingga 300-400 karyawan
  • Reliability: Uptime 99.9% dengan redundant components
  • Data Security: ECC RAM dan RAID protection mencegah data loss
  • ROI (Return on Investment): Estimasi 3-5 tahun lifecycle dengan minimal upgrade
  • Future Ready: Mendukung digitalisasi dan Industry 4.0 initiatives
