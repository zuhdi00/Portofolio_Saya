FLOWCHART PEMBUATAN STB LABEL

PT. Supracor Sejahtera - Corrugated Carton Box

Panduan Cepat untuk Operator

MULAI
↓

1. INPUT DATA STB

  • Nomor OP
  • Nama Customer
  • Kode Barang
  • Jumlah Barang
  • Generate Nomor STB Otomatis
↓
Nomor OP Valid?
✓ YA
Lanjut ke langkah berikutnya
✗ TIDAK
Cek nomor OP atau hubungi admin
↓

2. GENERATE & PRINT LABEL

  • Sistem generate QR Code
  • Print label STB
  • 1 STB = 1 Label
↓
QR Code Jelas & Terbaca?
✓ YA
Lanjut ke proses fisik
✗ TIDAK
Print ulang atau ganti printer
↓

3. TEMPEL LABEL PADA BARANG

  • Tempel di tempat yang jelas dan mudah terlihat
  • Pastikan label tidak terlipat atau rusak
  • Hindari area basah atau kotor
↓

4. SCAN QR CODE

  • Gunakan scanner atau kamera aplikasi
  • Pastikan pencahayaan cukup
  • Posisikan kamera tegak lurus dengan label
↓
Data Muncul di Aplikasi?
✓ YA
Data muncul dengan benar
✗ TIDAK
Bersihkan kamera, perbaiki cahaya, atau print ulang label
↓

5. VERIFIKASI FISIK BARANG

  • Cek kondisi fisik barang (rusak/baik)
  • Cocokkan data dengan barang fisik
  • Periksa jumlah/kuantitas barang
  • Verifikasi kesesuaian dengan PO/OP
↓
Barang Sesuai dengan Data?
✓ SESUAI
Lanjut ke approval
✗ TIDAK SESUAI
• Klik "Reject"
• Input alasan penolakan
• Informasikan supervisor
• Pisahkan barang reject
↓

6. APPROVAL

  • Klik tombol "Approve" di aplikasi
  • Data tersimpan otomatis di sistem
  • Label STB aktif dan siap digunakan
↓
SELESAI

✓ TIPS PENTING UNTUK OPERATOR

  • Akurasi Data: Pastikan semua data yang diinput 100% benar dan lengkap
  • Nomor STB Unik: Cek nomor STB terakhir agar tidak terjadi duplikasi
  • QR Code Jelas: Label harus tercetak tajam, jelas, dan mudah di-scan
  • Verifikasi Wajib: SELALU cek fisik barang sebelum melakukan approval
  • FIFO System: Terapkan First In First Out - barang masuk pertama keluar pertama
  • Dokumentasi: Ambil foto jika ada masalah untuk laporan ke supervisor

✗ YANG HARUS DIHINDARI

  • ❌ Nomor STB duplikat atau kembar
  • ❌ Label basah, kotor, robek, atau rusak
  • ❌ Approval tanpa verifikasi fisik barang
  • ❌ Salah input jumlah atau data barang
  • ❌ QR Code terlipat atau tidak terbaca
  • ❌ Label ditempel di tempat yang sulit di-scan
  • ❌ Mengabaikan prosedur FIFO
