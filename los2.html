PROSEDUR KERJA

1. Akses Sistem Buka browser → Ketik: edp2:8081/labelstb/
2. Input Nomor OP Ketik nomor OP di kolom "SPS" (Contoh: 2503/00990-B06) → Klik "Cari"
3. Periksa Hasil Jika label muncul, periksa semua data. Jika tidak muncul, cek kembali nomor OP.
⚠️ PASTIKAN SEMUA DATA SUDAH BENAR SEBELUM LANJUT
4. Input Data STB (3 Data Wajib) • Kepala Shift - Nama kepala shift
• Koli/Pallete - Jumlah (angka saja)
• Jumlah Tambahan - Isi 0 jika tidak ada
5. Cetak & Tempel Tekan CTRL + P → Cetak → Tempel label di pallete (QR Code harus terlihat jelas)
6. Bawa ke Gudang STB Pindahkan pallete ke gudang STB → Letakkan sesuai area
7. Scan QR & Verifikasi Scan QR Code → Cocokkan quantity dengan barang fisik
Jika Quantity TIDAK SESUAI: Hitung ulang → Lapor supervisor → STOP proses
Jika Quantity SESUAI: Lanjut ke langkah 8
8. Simpan Klik "Save" → Selesai

PENANGANAN MASALAH

Masalah Solusi
OP tidak ditemukan Cek penulisan → Hubungi PPIC
Printer error Cek koneksi → Hubungi IT
Quantity tidak sesuai Hitung ulang → Lapor supervisor
Sistem lambat Refresh (F5) → Restart browser
