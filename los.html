PROSEDUR OPERASIONAL STANDAR

Pembuatan Label STB (Serah Terima Barang)

Nama Prosedur: Pembuatan dan Pencetakan Label STB
Area: Produksi - Gudang
Penanggung Jawab: Operator Produksi
Sistem: edp2:8081/labelstb/

1. TUJUAN

Prosedur ini dibuat untuk memastikan operator produksi dapat membuat label STB dengan benar, akurat, dan efisien untuk keperluan identifikasi dan pelacakan barang.

2. RUANG LINGKUP

Prosedur ini berlaku untuk semua operator produksi yang bertanggung jawab dalam pembuatan label STB berdasarkan nomor OP (Order Produksi) yang diterima.

3. PERSIAPAN

  • Komputer/laptop dengan akses ke sistem edp2:8081/labelstb/
  • Printer yang sudah terkoneksi dan siap digunakan
  • Nomor OP (Order Produksi) yang valid
  • Koneksi jaringan server yang stabil

4. LANGKAH-LANGKAH PEMBUATAN LABEL STB

1 BUKA SISTEM LABEL STB
• Buka browser (Chrome/Firefox/Edge)
• Ketik alamat: edp2:8081/labelstb/
• Tunggu hingga halaman muncul dengan judul "Label STB Berdasarkan No. O.P"
2 INPUT NOMOR OP
• Lihat nomor OP pada dokumen produksi Anda
• Contoh nomor OP: 2503/00990-B06 atau 2511/00245-B01
• Ketik nomor OP pada kolom "SPS" yang tersedia
• Pastikan nomor OP diketik dengan benar (tanpa spasi di awal/akhir)
3 KLIK TOMBOL "CARI"
• Klik tombol biru "Cari" yang ada di bawah kolom input
• Tunggu beberapa detik hingga sistem memproses
• Sistem akan mencari data OP yang Anda masukkan
4 CEK HASIL PENCARIAN
JIKA NOMOR OP DITEMUKAN:
• Sistem akan menampilkan label STB dengan informasi lengkap
• Cek informasi yang muncul: Tanggal Cetak, Tanggal Kirim, No. STB, No. OP, Nama Barang, dll
• Label akan menampilkan QR Code untuk scanning
• Lanjut ke langkah berikutnya

JIKA NOMOR OP TIDAK DITEMUKAN:
• Sistem tidak akan menampilkan label
• Cek kembali nomor OP yang Anda input
• Pastikan format penulisan sudah benar
• Hubungi supervisor jika masalah berlanjut
⚠️ PERHATIAN PENTING!
Pastikan semua informasi pada label sudah sesuai sebelum melanjutkan ke proses input data. Data yang salah akan mempengaruhi proses selanjutnya.
5 INPUT DATA STB
Setelah label muncul, Anda perlu input 3 data penting:

A. Input Kepala Shift
• Masukkan nama kepala shift yang bertugas
• Contoh: "Budi Santoso" atau "Ahmad"

B. Input Koli/Pallete
• Masukkan jumlah koli atau pallete
• Gunakan angka saja (contoh: 50, 100)
• Pastikan sesuai dengan jumlah fisik barang

C. Input Jumlah Tambahan
• Masukkan jumlah tambahan jika ada
• Jika tidak ada tambahan, isi dengan 0 (nol)
• Contoh: jika ada tambahan 5 pcs, isi "5"
6 TEMPELKAN LABEL STB PADA PALLETE
• Ambil label STB yang sudah tercetak
• Tempelkan label pada posisi yang mudah terlihat di pallete/kardus
• Pastikan label tidak tertutup atau terlipat
• QR Code harus bisa di-scan dengan jelas
7 BAWA PALLETE KE GUDANG STB
• Bawa pallete yang sudah diberi label ke area gudang STB
• Letakkan sesuai dengan area yang ditentukan
• Pastikan label menghadap ke luar dan mudah terlihat
8 VERIFIKASI QUANTITY DENGAN SCAN QR
• Gunakan scanner QR Code
• Scan QR Code pada label STB
• Sistem akan menampilkan data quantity
• Cocokkan dengan jumlah fisik barang
9 CEK KESESUAIAN JUMLAH
JIKA JUMLAH QUANTITY TIDAK SESUAI:
• JANGAN lanjutkan proses
• Hitung ulang jumlah barang secara manual
• Laporkan ke supervisor shift
• Tunggu instruksi untuk perbaikan data
• Ulangi dari langkah 1 jika perlu membuat label baru

JIKA JUMLAH QUANTITY SESUAI:
• Lanjut ke proses berikutnya (langkah 10)
10 PROSES APPROVAL DAN SIMPAN
• Setelah semua data benar, klik tombol "Save" pada sistem
• Jika ingin mencetak ulang, klik "Print"
• Gunakan shortcut keyboard: CTRL + P untuk print cepat
• Sistem akan menyimpan data STB ke database
• Barang siap untuk proses selanjutnya
11 SELESAI
• Proses pembuatan label STB selesai
• Barang sudah ter-approval dan tersimpan di sistem
• Siap untuk proses pengiriman ke gudang
• Dokumentasikan nomor STB untuk tracking
💡 TIPS & TRIK
  • Simpan daftar nomor OP yang sering digunakan untuk memudahkan input
  • Pastikan printer selalu siap dan memiliki cukup kertas label
  • Gunakan CTRL + P untuk mempercepat proses cetak
  • Selalu cek koneksi internet sebelum memulai
  • Jika sistem lambat, refresh halaman dengan menekan F5
  • Catat nomor STB untuk referensi dan pelacakan

5. TROUBLESHOOTING (PENYELESAIAN MASALAH)

❌ Masalah: Nomor OP tidak ditemukan
✅ Solusi:
  • Periksa kembali penulisan nomor OP
  • Pastikan tidak ada spasi di awal atau akhir
  • Cek format penulisan (contoh: 2503/00990-B06)
  • Konfirmasi ke bagian PPIC apakah OP sudah diinput ke sistem
❌ Masalah: Printer tidak berfungsi
✅ Solusi:
  • Cek koneksi printer ke komputer
  • Pastikan printer dalam kondisi online
  • Periksa ketersediaan kertas dan tinta
  • Restart printer jika perlu
  • Hubungi IT support jika masalah berlanjut
❌ Masalah: Data quantity tidak sesuai
✅ Solusi:
  • Hitung ulang jumlah fisik barang
  • Periksa apakah ada barang yang reject
  • Laporkan ke supervisor untuk investigasi
  • Jangan lanjutkan proses sampai masalah terselesaikan
❌ Masalah: Sistem lambat atau tidak merespon
✅ Solusi:
  • Refresh halaman dengan menekan F5
  • Tutup browser dan buka kembali
  • Cek koneksi internet
  • Restart komputer jika diperlukan
  • Hubungi IT support jika sistem tetap down
