🔧 Panduan Konfigurasi VLAN Mikrotik via Winbox

Memisahkan Jaringan Office dan CCTV untuk Menghindari Traffic Collision

📚 Quick Navigation: Topologi | Perencanaan | Konfigurasi | Testing | Troubleshooting
💡 Tujuan Konfigurasi:
  • Memisahkan traffic jaringan Office dan CCTV menggunakan VLAN
  • Mencegah bandwidth CCTV membebani jaringan Office
  • Meningkatkan keamanan dan performa jaringan
  • Mengelola QoS untuk prioritas traffic

📊 Topologi Jaringan

INTERNET | | [MIKROTIK ROUTER] | ├─── ether1: WAN (Internet) ├─── ether2: Bridge (Trunk Port - Tagged) | | [MANAGED SWITCH] | ├─── Port 1-10: VLAN 10 (Office Network) - Untagged ├─── Port 11-16: VLAN 20 (CCTV Network) - Untagged └─── Port 24: Trunk ke Mikrotik - Tagged VLAN 10 (Office Network) ├─── Server ├─── Komputer Client 1-10 └─── Printer VLAN 20 (CCTV Network) ├─── NVR/DVR └─── IP Camera 1-8

📋 Perencanaan IP Address

VLAN Nama Network Gateway DHCP Range Fungsi
VLAN 10 Office 192.168.10.0/24 192.168.10.1 192.168.10.100-200 Server, Client, Printer
VLAN 20 CCTV 192.168.20.0/24 192.168.20.1 192.168.20.100-200 NVR, IP Camera
⚠️ Persiapan Sebelum Konfigurasi:
  • Backup konfigurasi Mikrotik yang ada
  • Siapkan managed switch yang support VLAN
  • Catat IP address dan port yang akan digunakan
  • Pastikan koneksi Winbox stabil

⚙️ Langkah Konfigurasi via Winbox

1 Login ke Mikrotik via Winbox

  1. Buka aplikasi Winbox
  2. Connect ke Mikrotik menggunakan:
    • IP Address atau MAC Address
    • Username: admin
    • Password: [password Anda]
  3. Klik Connect
💡 Tips: Gunakan MAC Address jika IP belum dikonfigurasi atau terjadi masalah koneksi

2 Membuat Bridge untuk VLAN

📂 Winbox → Bridge → Tab Bridge → Klik [+]

Konfigurasi Bridge:

Name bridge-vlan
VLAN Filtering ✓ Checked (Centang)

Klik OK

✓ Bridge berhasil dibuat dengan nama "bridge-vlan"

3 Menambahkan Port ke Bridge

📂 Winbox → Bridge → Tab Ports → Klik [+]

Tambahkan Interface yang akan di-bridge:

Port 1 - ether2 (ke Switch):

Interface ether2
Bridge bridge-vlan

Klik OK

💡 Ulangi untuk interface lain yang ingin dimasukkan ke bridge (ether3, ether4, dll)

4 Membuat VLAN Interface

📂 Winbox → Interfaces → Klik [+] → Pilih VLAN

VLAN 10 - Office:

Name vlan10-office
VLAN ID 10
Interface bridge-vlan

Klik OK

VLAN 20 - CCTV:

Name vlan20-cctv
VLAN ID 20
Interface bridge-vlan

Klik OK

✓ VLAN 10 dan VLAN 20 berhasil dibuat

5 Konfigurasi VLAN di Bridge

📂 Winbox → Bridge → Tab VLANs → Klik [+]

VLAN 10 - Office:

Bridge bridge-vlan
VLAN IDs 10
Tagged ether2 (port ke switch)
Untagged -

Klik OK

VLAN 20 - CCTV:

Bridge bridge-vlan
VLAN IDs 20
Tagged ether2 (port ke switch)
Untagged -

Klik OK

6 Konfigurasi IP Address untuk VLAN

📂 Winbox → IP → Addresses → Klik [+]

IP Address VLAN 10 (Office):

Address 192.168.10.1/24
Interface vlan10-office

Klik OK

IP Address VLAN 20 (CCTV):

Address 192.168.20.1/24
Interface vlan20-cctv

Klik OK

7 Konfigurasi DHCP Server untuk VLAN

📌 DHCP Server untuk VLAN 10 (Office)

📂 Winbox → IP → DHCP Server → Klik DHCP Setup
  1. DHCP Server Interface: vlan10-office → Next
  2. DHCP Address Space: 192.168.10.0/24 → Next
  3. Gateway for DHCP Network: 192.168.10.1 → Next
  4. Addresses to Give Out: 192.168.10.100-192.168.10.200 → Next
  5. DNS Servers: 8.8.8.8, 8.8.4.4 → Next
  6. Lease Time: 1d 00:00:00 → Next

📌 DHCP Server untuk VLAN 20 (CCTV)

Ulangi proses yang sama dengan parameter:

  1. DHCP Server Interface: vlan20-cctv
  2. DHCP Address Space: 192.168.20.0/24
  3. Gateway: 192.168.20.1
  4. Address Range: 192.168.20.100-192.168.20.200
  5. DNS: 8.8.8.8, 8.8.4.4

8 Konfigurasi NAT (Masquerade)

📂 Winbox → IP → Firewall → Tab NAT → Klik [+]

Tab General:

Chain srcnat
Out. Interface ether1 (WAN/Internet)

Tab Action:

Action masquerade

Klik OK

💡 NAT rule ini memungkinkan kedua VLAN mengakses internet

9 Konfigurasi QoS - Membatasi Bandwidth CCTV

⚠️ Penting: QoS mencegah traffic CCTV membebani jaringan Office
📂 Winbox → Queues → Tab Simple Queues → Klik [+]

Limit Bandwidth CCTV:

Tab General:

Name CCTV-Limit
Target 192.168.20.0/24
Max Limit (Download) 20M (20 Mbps)
Max Limit (Upload) 10M (10 Mbps)

Klik OK

💡 Sesuaikan limit bandwidth dengan kebutuhan CCTV Anda. Formula: Jumlah Kamera × 2-4 Mbps

Prioritas Traffic Office (Opsional):

Name Office-Priority
Target 192.168.10.0/24
Priority 1 (highest)

10 Konfigurasi Firewall Rules (Isolasi VLAN)

📂 Winbox → IP → Firewall → Tab Filter Rules → Klik [+]

Blokir CCTV mengakses Office (Keamanan):

Tab General:

Chain forward
Src. Address 192.168.20.0/24 (CCTV)
Dst. Address 192.168.10.0/24 (Office)

Tab Action:

Action drop

Klik OK

Izinkan Office mengakses CCTV (untuk monitoring):

Tab General:

Chain forward
Src. Address 192.168.10.0/24 (Office)
Dst. Address 192.168.20.0/24 (CCTV)

Tab Action:

Action accept

Klik OK

11 Konfigurasi Switch - VLAN Tagging

⚠️ Catatan: Langkah ini dilakukan pada Managed Switch Anda (bukan di Mikrotik)

Konfigurasi di Switch:

Port VLAN Mode Perangkat
Port 1-10 10 Access/Untagged Server, Client Office
Port 11-16 20 Access/Untagged NVR, IP Camera
Port 24 10, 20 Trunk/Tagged Uplink ke Mikrotik

Contoh konfigurasi pada switch berbeda:

TP-Link / D-Link:
1. Masuk web interface switch
2. VLAN → 802.1Q VLAN → Create VLAN 10 dan 20
3. Port Config → Set port 1-10 ke VLAN 10 (Untagged)
4. Port Config → Set port 11-16 ke VLAN 20 (Untagged)
5. Port Config → Set port 24 ke VLAN 10,20 (Tagged/Trunk)
Cisco Switch:
interface range gi0/1-10
  switchport mode access
  switchport access vlan 10
!
interface range gi0/11-16
  switchport mode access
  switchport access vlan 20
!
interface gi0/24
  switchport mode trunk
  switchport trunk allowed vlan 10,20

🧪 Testing dan Verifikasi

12 Testing Konektivitas

Test 1: Ping Gateway dari Client Office

C:\> ping 192.168.10.1

✓ Reply dari 192.168.10.1: bytes=32 time<1ms TTL=64

Test 2: Ping Gateway dari CCTV/NVR

> ping 192.168.20.1

✓ Reply dari 192.168.20.1: bytes=32 time<1ms TTL=64

Test 3: Ping Internet dari Office

C:\> ping 8.8.8.8

✓ Reply dari 8.8.8.8: bytes=32 time=15ms TTL=118

Test 4: Test Isolasi VLAN (dari CCTV ping ke Office)

> ping 192.168.10.100

✗ Request timed out (ini yang diharapkan - CCTV tidak bisa akses Office)

Test 5: Test Akses dari Office ke CCTV (untuk monitoring)

C:\> ping 192.168.20.100

✓ Reply dari 192.168.20.100: bytes=32 time<1ms TTL=64

13 Monitoring Traffic di Mikrotik

📂 Winbox → Interfaces

Perhatikan TX/RX pada setiap interface VLAN:

Interface Yang Harus Dicek
vlan10-office Traffic data office normal, tidak terpengaruh CCTV
vlan20-cctv Traffic CCTV terbatas sesuai QoS yang dikonfigurasi
📂 Winbox → Queues → Simple Queues

Monitor bandwidth CCTV real-time untuk memastikan tidak melebihi limit

📂 Winbox → IP → Firewall → Tab Filter Rules

Cek counter pada firewall rule untuk memastikan isolasi VLAN bekerja

14 Verifikasi DHCP

📂 Winbox → IP → DHCP Server → Tab Leases

Pastikan perangkat mendapat IP sesuai VLAN:

  • Client Office mendapat IP 192.168.10.x
  • CCTV/NVR mendapat IP 192.168.20.x
  • Tidak ada IP conflict
  • Gateway dan DNS sudah benar

🔧 Troubleshooting

❌ Masalah 1: Client Tidak Dapat IP DHCP

Penyebab:

  • DHCP Server belum aktif
  • VLAN tidak dikonfigurasi dengan benar di switch
  • Port switch tidak dalam mode yang benar

Solusi:

  1. Cek status DHCP Server di Mikrotik
  2. Pastikan VLAN ID di switch sama dengan Mikrotik
  3. Verifikasi port mode (Access vs Trunk)
  4. Restart DHCP Server jika perlu
Cek DHCP Server via Terminal:
/ip dhcp-server print
/ip dhcp-server lease print

❌ Masalah 2: Tidak Bisa Akses Internet

Penyebab:

  • NAT Masquerade belum dikonfigurasi
  • Default route belum ada
  • DNS Server tidak dikonfigurasi

Solusi:

  1. Cek NAT rule di Firewall → NAT
  2. Cek default route di IP → Routes
  3. Test ping ke 8.8.8.8 (IP) dan google.com (DNS)
Cek Routing via Terminal:
/ip route print
/ip firewall nat print
/ping 8.8.8.8

❌ Masalah 3: VLAN Masih Bisa Saling Akses

Penyebab:

  • Firewall rule belum dikonfigurasi
  • Urutan firewall rule salah
  • VLAN filtering di bridge belum diaktifkan

Solusi:

  1. Pastikan VLAN Filtering di Bridge = checked
  2. Cek urutan firewall rules (drop rule harus di atas accept rule)
  3. Test dengan ping antar VLAN

❌ Masalah 4: CCTV Masih Membebani Jaringan Office

Penyebab:

  • QoS/Queue belum dikonfigurasi
  • Limit bandwidth terlalu besar
  • Queue tidak aktif

Solusi:

  1. Cek Simple Queue → pastikan ada dan aktif
  2. Turunkan limit bandwidth CCTV jika perlu
  3. Monitor real-time bandwidth di Queues
  4. Adjust limit sesuai jumlah kamera
Formula Bandwidth CCTV:
Bandwidth = Jumlah Kamera × Bitrate per Kamera

Contoh:
8 kamera × 2 Mbps = 16 Mbps
Tambah buffer 20% = 19-20 Mbps

❌ Masalah 5: Loss Connection ke Mikrotik saat Konfigurasi

Penyebab:

  • Interface Winbox terputus karena perubahan VLAN
  • IP management berubah

Solusi Pencegahan:

  1. Gunakan MAC Address untuk connect Winbox (bukan IP)
  2. Backup konfigurasi sebelum mulai
  3. Jangan matikan semua interface sekaligus
  4. Siapkan akses console/serial sebagai backup
🚨 Tips Penting: Jika terputus, reconnect via MAC Address. MAC tetap terdeteksi meskipun IP berubah.

✅ Checklist Konfigurasi Selesai

  • Bridge dengan VLAN Filtering sudah dibuat
  • Port sudah ditambahkan ke Bridge
  • VLAN Interface (vlan10, vlan20) sudah dibuat
  • VLAN sudah dikonfigurasi di Bridge VLANs
  • IP Address sudah di-assign ke setiap VLAN
  • DHCP Server aktif di kedua VLAN
  • NAT Masquerade sudah dikonfigurasi
  • QoS/Queue untuk limit bandwidth CCTV sudah aktif
  • Firewall rules untuk isolasi VLAN sudah dikonfigurasi
  • Switch sudah dikonfigurasi dengan VLAN tagging yang benar
  • Testing konektivitas berhasil
  • Monitoring traffic normal

📊 Hasil yang Diharapkan

✓ Setelah Konfigurasi Berhasil:

  • Jaringan Office tidak terganggu oleh traffic CCTV
  • Bandwidth CCTV terbatas sesuai kebutuhan (tidak menghabiskan semua bandwidth)
  • Keamanan meningkat - CCTV tidak bisa akses jaringan Office
  • Office bisa monitoring CCTV - akses satu arah dari Office ke CCTV
  • Kedua jaringan bisa akses internet secara independen
  • Mudah di-manage - traffic terpisah dan mudah dimonitor

📝 Command Line Alternative (Terminal)

💡 Untuk yang lebih suka menggunakan Terminal, berikut command lengkapnya:
# 1. Buat Bridge dengan VLAN Filtering
/interface bridge add name=bridge-vlan vlan-filtering=yes
# 2. Tambahkan Port ke Bridge
/interface bridge port add interface=ether2 bridge=bridge-vlan
# 3. Buat VLAN Interface
/interface vlan add name=vlan10-office vlan-id=10 interface=bridge-vlan /interface vlan add name=vlan20-cctv vlan-id=20 interface=bridge-vlan
# 4. Konfigurasi Bridge VLANs
/interface bridge vlan add bridge=bridge-vlan vlan-ids=10 tagged=ether2 /interface bridge vlan add bridge=bridge-vlan vlan-ids=20 tagged=ether2
# 5. Set IP Address
/ip address add address=192.168.10.1/24 interface=vlan10-office /ip address add address=192.168.20.1/24 interface=vlan20-cctv
# 6. Konfigurasi DHCP Pool
/ip pool add name=pool-office ranges=192.168.10.100-192.168.10.200 /ip pool add name=pool-cctv ranges=192.168.20.100-192.168.20.200
# 7. Setup DHCP Server
/ip dhcp-server add name=dhcp-office interface=vlan10-office address-pool=pool-office disabled=no /ip dhcp-server add name=dhcp-cctv interface=vlan20-cctv address-pool=pool-cctv disabled=no
# 8. Set DHCP Network
/ip dhcp-server network add address=192.168.10.0/24 gateway=192.168.10.1 dns-server=8.8.8.8,8.8.4.4 /ip dhcp-server network add address=192.168.20.0/24 gateway=192.168.20.1 dns-server=8.8.8.8,8.8.4.4
# 9. Konfigurasi NAT
/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade
# 10. QoS - Limit Bandwidth CCTV
/queue simple add name=CCTV-Limit target=192.168.20.0/24 max-limit=20M/10M
# 11. Firewall - Isolasi VLAN
/ip firewall filter add chain=forward src-address=192.168.20.0/24 dst-address=192.168.10.0/24 action=drop comment="Block CCTV to Office" /ip firewall filter add chain=forward src-address=192.168.10.0/24 dst-address=192.168.20.0/24 action=accept comment="Allow Office to CCTV"
# 12. Aktifkan VLAN Filtering
/interface bridge set bridge-vlan vlan-filtering=yes
⚠️ Perhatian: Copy command satu per satu dan tunggu sampai selesai. Jangan paste semua sekaligus untuk menghindari error.

🔄 Backup dan Restore Konfigurasi

Backup Konfigurasi

📂 Winbox → Files → Klik Backup

Atau via Terminal:

/system backup save name=backup-vlan-config

Download file backup dari Files menu untuk disimpan di komputer

Export Konfigurasi (Text Format)

/export file=config-vlan

File akan tersimpan di Files dan bisa di-download

🎯 Best Practices

  • Gunakan VLAN ID standar: Hindari VLAN 1 (default), mulai dari VLAN 10
  • Dokumentasi: Catat semua VLAN ID, IP range, dan fungsinya
  • Label kabel: Tandai kabel dengan label VLAN untuk memudahkan maintenance
  • Regular backup: Backup konfigurasi Mikrotik setiap ada perubahan
  • Monitor bandwidth: Pantau penggunaan bandwidth secara berkala
  • Update firmware: Pastikan Mikrotik dan switch menggunakan firmware terbaru
  • Testing berkala: Test isolasi VLAN dan QoS secara periodik
