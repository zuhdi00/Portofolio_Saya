📊 FLOWCHART PEMBUATAN STB LABEL

PT. Supracor Sejahtera - Corrugated Carton Box

Panduan Cepat untuk Operator

🚀
MULAI
Operator siap membuat STB Label
↓
1 INPUT NOMOR OP
📝 Buka Link STB Label
📝 Masukkan nomor Order Produksi (OP)
📝 Klik tombol "Cari" atau tekan Enter
↓
❓ DATA OP DITEMUKAN?
❌
TIDAK
Cek nomor OP
atau hubungi admin
✅
YA
Lanjut ke langkah berikutnya
↓
2 INPUT DATA STB
✏️ Nomor STB terbaru (pastikan unik)
✏️ Nama Kepala Shift
✏️ Jumlah Koli/Pallete
✏️ Jumlah Tambahan (PCS)
↓
3 SAVE & PRINT LABEL
💾 Klik tombol "Save"
🖨️ Klik tombol "Print Preview"
🖨️ Print label dengan QR Code
↓
❓ LABEL TERCETAK JELAS?
❌
TIDAK
Print ulang
atau ganti printer
✅
YA
Lanjut ke proses fisik
↓
4 TEMPEL LABEL DI PALLET
📋 Tempel label pada tumpukan kardus per pallet
📋 Posisi: depan atas (mudah terlihat)
📋 Pastikan label menempel kuat
↓
5 BAWA KE GUDANG STB
🚛 Gunakan forklift untuk memindahkan pallet
🚛 Bawa ke area Gudang STB
🚛 Tempatkan di area staging
↓
6 SCAN QR CODE
📱 Buka aplikasi "Barcode SPS"
📱 Pilih menu "Scan Barcode"
📱 Scan QR Code pada label STB
📱 Tunggu data muncul di layar
↓
❓ QR CODE TERBACA?
❌
TIDAK
Bersihkan kamera
Perbaiki cahaya
atau print ulang label
✅
YA
Data muncul di aplikasi
↓
7 VERIFIKASI DATA & BARANG
✓ Cek Nomor OP sesuai dokumen
✓ Cek Nama Barang sesuai fisik
✓ Hitung Jumlah Koli/Pallet
✓ Cek Ukuran & Kualitas kardus
✓ Pastikan kondisi fisik baik (tidak rusak)
↓
❓ BARANG SESUAI?
❌
TIDAK SESUAI
Klik "Reject"
Input alasan
Informasikan supervisor
Pisahkan barang
✅
SESUAI
Lanjut approval
↓
8 LAKUKAN APPROVAL
✅ Klik tombol "Approve" di aplikasi
✅ Konfirmasi approval
✅ Tunggu notifikasi berhasil
✅ Status berubah menjadi "Approved"
↓
9 SIMPAN DI GUDANG STB
📦 Tentukan lokasi penyimpanan (FIFO)
📦 Pindahkan pallet ke lokasi yang tepat
📦 Update lokasi di sistem (jika ada)
📦 Rapikan area penyimpanan
↓
🎉
SELESAI
✓ Label STB terpasang
✓ Data tercatat di sistem
✓ Barang tersimpan di gudang
✓ Siap untuk pengiriman

💡 Tips Penting untuk Operator:

  • Akurasi Data: Pastikan semua data yang diinput 100% benar
  • Nomor STB Unik: Cek nomor terakhir agar tidak duplikat
  • QR Code Jelas: Label harus tercetak dengan jelas dan mudah di-scan
  • Verifikasi Wajib: Selalu cek fisik barang sebelum approval
  • FIFO System: Barang masuk pertama keluar pertama
  • Dokumentasi: Foto jika ada masalah untuk laporan

⚠️ Yang Harus Dihindari:

  • ❌ Nomor STB duplikat
  • ❌ Label basah, kotor, atau rusak
  • ❌ Approval tanpa verifikasi fisik
  • ❌ Salah input jumlah atau data
  • ❌ QR Code terlipat atau tidak terbaca
