Standard Operating Procedure

Pembuatan Label STB (Serah Terima Barang)

Tanggal Efektif : Januari 2026
Departemen : EDP
Penanggung Jawab : Information Technology Staff

1. Tujuan

Memberikan panduan standar kepada operator produksi dalam membuat dan mencetak label STB yang akurat untuk identifikasi dan pelacakan barang produksi.

2. Ruang Lingkup

SOP ini berlaku untuk seluruh operator produksi yang bertugas membuat label STB berdasarkan nomor OP (Order Produksi).

3. Definisi

  • STB : Serah Terima Barang
  • OP : Order Produksi (Nomor referensi produksi)
  • QR Code : Kode batang untuk scanning otomatis
  • Pallete : Tempat/wadah penumpukan barang

4. Alat dan Bahan

  • Komputer dengan akses ke sistem edp2:8081/labelstb/
  • Printer dan kertas label
  • Nomor OP yang valid
  • Scanner QR Code

5. Prosedur Kerja

LANGKAH 1: Akses Sistem
  • Buka browser di komputer
  • Ketik alamat: edp2:8081/labelstb/
  • Tunggu halaman terbuka
LANGKAH 2: Input Nomor OP
  • Ketik nomor OP pada kolom "SPS"
  • Format: 2503/00990-B06
  • Pastikan tidak ada spasi di awal atau akhir
LANGKAH 3: Cari Data
  • Klik tombol "Cari"
  • Tunggu sistem memproses
  • Jika OP tidak ditemukan, periksa kembali nomor yang diinput
PERHATIAN: Pastikan semua informasi pada label yang muncul sudah benar sebelum melanjutkan ke langkah berikutnya.
LANGKAH 4: Input Data STB
Masukkan 3 data berikut:
  • Kepala Shift - Nama kepala shift yang bertugas
  • Koli/Pallete - Jumlah koli/pallete (gunakan angka saja)
  • Jumlah Tambahan - Isi 0 jika tidak ada tambahan
LANGKAH 5: Cetak dan Tempel Label
  • Klik tombol "Print" atau tekan CTRL + P
  • Cetak label
  • Tempelkan label pada pallete di posisi yang mudah terlihat
  • Pastikan QR Code tidak tertutup atau terlipat
LANGKAH 6: Pindahkan ke Gudang STB
  • Bawa pallete yang sudah diberi label ke gudang STB
  • Letakkan sesuai area yang ditentukan
  • Pastikan label menghadap ke luar
LANGKAH 7: Verifikasi dengan Scan QR
  • Scan QR Code pada label menggunakan scanner
  • Sistem akan menampilkan data quantity
  • Cocokkan dengan jumlah fisik barang

Jika quantity TIDAK SESUAI:
  • Hitung ulang barang secara manual
  • Laporkan ke supervisor shift
  • JANGAN lanjutkan proses

Jika quantity SESUAI:
  • Lanjut ke langkah berikutnya
LANGKAH 8: Simpan Data
  • Klik tombol "Save" pada sistem
  • Data STB akan tersimpan di database
  • Barang siap untuk proses selanjutnya

6. Penanganan Masalah

Masalah Solusi
Nomor OP tidak ditemukan • Periksa kembali penulisan nomor OP
• Pastikan format penulisan benar
• Hubungi bagian PPIC
Printer tidak berfungsi • Cek koneksi printer
• Periksa kertas dan tinta
• Hubungi IT Support
Data quantity tidak sesuai • Hitung ulang barang
• Laporkan ke supervisor
• Jangan lanjutkan proses
Sistem lambat/error • Refresh halaman (F5)
• Restart browser
• Hubungi IT Support
