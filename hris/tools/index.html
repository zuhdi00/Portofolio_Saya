🔄 Tools Migrasi Data Pegawai

Sistem otomatis untuk membandingkan dan memindahkan data dari CSV ke SQL Server

📌 Informasi Penting

Database Source: CSV file (DATA KARYAWAN (2).csv)

Database Target: SQL Server - dbHR (spsdmz2)

Mode Perbandingan: Case-insensitive (huruf besar/kecil diabaikan)

⚠️ Backup Terlebih Dahulu

Sebelum menjalankan migrasi, pastikan Anda telah melakukan backup database dbHR untuk keamanan data.

Data Comparison Tool

Bandingkan data antara CSV dan SQL Server dengan detail. Lihat data mana saja yang berbeda, duplikat, atau hanya ada di salah satu sumber.

  • Perbandingan case-insensitive
  • Deteksi data yang sama
  • Identifikasi perbedaan detail
  • Laporan komprehensif
Jalankan Analisis
🚀

Migration Tool

Migrasi data otomatis dari CSV ke SQL Server dengan mode DRY RUN untuk preview terlebih dahulu sebelum commit perubahan.

  • Mode DRY RUN (preview aman)
  • Auto INSERT data baru
  • Auto UPDATE data existing
  • Error handling & rollback
Mulai Migrasi
💾

SQL Script Generator

Generate SQL migration script lengkap yang bisa dijalankan langsung di SQL Server Management Studio (SSMS) atau command line.

  • Export sebagai .sql file
  • Bisa dijalankan di SSMS
  • Include backup instructions
  • Auto verification queries

❓ Pertanyaan Yang Sering Diajukan

Q: Apakah perbedaan huruf besar/kecil akan dianggap berbeda?
A: Tidak. Sistem menggunakan case-insensitive comparison, jadi "SUDIONO" dan "Sudiono" dianggap sama.

Q: Apa itu mode DRY RUN?
A: Mode preview yang menunjukkan perubahan apa yang akan dilakukan tanpa benar-benar mengubah database. Gunakan ini untuk verifikasi sebelum eksekusi sesungguhnya.

Q: Bagaimana jika ada error saat migrasi?
A: Sistem akan mencatat error dan menampilkan detailnya. Anda bisa memperbaiki data CSV dan mencoba lagi.

Q: Bisa di-rollback jika ada kesalahan?
A: Gunakan backup yang telah Anda buat sebelum migrasi. Itulah mengapa backup sangat penting!
