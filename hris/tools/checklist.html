⚙️ Requirement Details

1. XAMPP Status

Apache & MySQL harus berjalan. Cek:

Services → XAMPP Control Panel → Click "Start" pada Apache & MySQL
2. PHP Extensions

Cek di phpinfo():

- php_sqlsrv (untuk SQL Server connection)
- mysqli (sudah default di XAMPP)
3. SQL Server Connection

Test connection dengan credentials:

Server: spsdmz2
User: sa
Password: supracor
Database: dbHR
4. Backup Strategy

Backup database dbHR menggunakan SSMS:

Right-click dbHR → Tasks → Back Up
Location: C:\Backups\ (atau tempat aman lainnya)
Verify: Test restore ke database baru
5. Network Check

Test connection ke server spsdmz2:

CMD → ping spsdmz2
Atau: telnet spsdmz2 1433 (untuk SQL Server port)
