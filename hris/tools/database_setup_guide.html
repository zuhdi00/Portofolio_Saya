📋 Setup Instructions

✓ Tahap 1: Persiapan

1 Download Setup Script

File setup_database.sql sudah tersedia di folder tools.

Lokasi: c:\xampp\htdocs\hris\tools\setup_database.sql

✓ Tahap 2: Eksekusi Setup di SSMS

2 Buka SQL Server Management Studio (SSMS)

Program: Microsoft SQL Server Management Studio
Jika belum install: Download dari Microsoft SSMS

3 Koneksi ke Server

Server Name: spsdmz2
Authentication: SQL Server Authentication
Login: sa
Password: supracor

Klik "Connect" untuk koneksi ke database server.

4 Select Database

Di Object Explorer (sebelah kiri), expand node server dan pilih database:

Databases → dbHR

5 Buka Setup Script

Menu: File → Open → File

Cari dan buka file: setup_database.sql

6 Review Script

Script akan:

  • ✓ Membuat tabel dbo.pegawai_lengkap
  • ✓ Membuat tabel pendukung lainnya
  • ✓ Membuat indexes untuk performa
  • ✓ Verifikasi setup

CATATAN: Script aman, tidak akan menghapus data yang sudah ada

7 Eksekusi Script

Klik button Execute (F5) atau tekan tombol Execute di toolbar

⚠️ Tunggu hingga proses selesai (jangan buka tab lain atau minimize SSMS)

8 Verifikasi Hasil

Di tab "Messages", Anda akan melihat output seperti:

Table dbo.pegawai_lengkap created successfully.
Table dbo.pegawai_keluarga created successfully.
✓ DATABASE SETUP COMPLETE!

🐛 Troubleshooting

Error: "Login failed for user 'sa'"

Solusi:

  • Cek credentials di koneksi_sqlsrv.php
  • Pastikan user 'sa' exist dan aktif di SQL Server
  • Cek apakah password 'supracor' benar
  • Pastikan SQL Server Authentication sudah enabled di SSMS
Error: "Cannot open network session"

Solusi:

  • Cek apakah server spsdmz2 accessible: ping spsdmz2
  • Cek firewall settings
  • Cek apakah SQL Server service sedang berjalan
  • Cek konfigurasi network di SQL Server Configuration Manager
Error: "Script execution timeout"

Solusi:

  • Tunggu lebih lama, jangan interrupt proses
  • Jalankan script di non-peak hours
  • Buka SSMS di machine yang dekat dengan server
  • Cek apakah ada query lain yang sedang running
